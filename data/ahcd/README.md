# Shared AHCD inputs

For the complete teammate setup and loading instructions, see [Team_Setup_and_Data_Access.md](../../04_neural-networks/Team_Setup_and_Data_Access.md).

Dataset: Arabic Handwritten Characters Dataset (AHCD), selected from https://www.kaggle.com/datasets/mloey1/ahcd1. The authors' repository is https://github.com/mloey/Arabic-Handwritten-Characters-Dataset.

`AHCD.zip` contains the four original CSV files supplied for this project. The original training portion has 13,440 images. The separate original test portion has 3,360 images. Each image has 1,024 pixels representing a 32 by 32 grayscale character, with original labels 1 to 28.

The `shared` folder contains ready to load files for the CNN experiments:

| File | Contents |
| --- | --- |
| `training_data.npz` | `images`: upright uint8 arrays with shape (13440, 1, 32, 32). `labels`: int64 labels 0 to 27. Row order matches the original training CSV. |
| `split_indices.npz` | `train_indices` and `validation_indices`, indexing those shared rows |
| `label_mapping.json` | Internal labels 0 to 27 mapped to original labels 1 to 28 |
| `data_info.json` | Dataset sources, shapes, preprocessing and split settings |

Images were reshaped, then transposed once to restore orientation and given a channel dimension. Do not transpose the prepared images again. Pixel scaling happens in each notebook using one division by 255. Do not divide twice.

The split uses `train_test_split` with stratification, 20% validation and random state 42. It has 10,752 fitting rows and 2,688 validation rows. Reuse these saved indices, even if you choose another random seed for weight initialization.

The stored arrays use channel first format. TensorFlow/Keras expects channel last format, so the loader moves the channel axis without changing image orientation. From a notebook inside `04_neural-networks`, use:

```python
from pathlib import Path
import numpy as np

shared_folder = Path("../data/ahcd/shared")
with np.load(shared_folder / "training_data.npz", allow_pickle=False) as data:
    images = np.moveaxis(data["images"], 1, -1).astype(np.float32) / 255.0
    labels = data["labels"].astype(np.int64)
with np.load(shared_folder / "split_indices.npz", allow_pickle=False) as split:
    train_indices = split["train_indices"]
    validation_indices = split["validation_indices"]
# Exclude blank fitting images without rewriting the saved shared indices.
has_visible_pixels = np.any(images != 0, axis=(1, 2, 3))
train_indices = train_indices[has_visible_pixels[train_indices]]
X_train, y_train = images[train_indices], labels[train_indices]
X_valid, y_valid = images[validation_indices], labels[validation_indices]
```

No preparation rerun is needed after cloning the branch. `prepare_shared_data.py` documents how to rebuild the shared files from the included archive using standard libraries. It refuses to overwrite existing arrays or indices. For a deliberately new data version, use a separate folder with the archive and script, then run the script there and coordinate the change before any new comparisons.

The baseline notebook does not open the original test CSVs. Keep those for the team's later evaluation after choosing a final configuration using validation results. Preserve this folder structure when uploading files to GitHub.

## Fixed diagnostic examples

`shared/baseline_mistake_indices.npz` is an additional diagnostic selection generated by the baseline notebook. Its `original_training_indices` array identifies up to 12 errors from the first published baseline validation predictions. It does not change `training_data.npz`, `split_indices.npz` or class labels.

Keep this selection unchanged when teammates compare predictions on the baseline's mistakes. It is deliberately restricted to initial baseline errors, so it cannot estimate overall performance. Use the full validation metrics for that purpose. The optional selection is reused if it already exists and is not part of the raw data preparation script.

## Filter used by the included models

The stored split contains 10,752 fitting rows. The included Keras notebook excludes its one all-zero image, row 6050, when loading inputs. Effective fitting count is 10,751. Validation remains 2,688. The stored arrays and indices are unchanged.
